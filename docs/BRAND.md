# Brand Guidelines — 9X Wealth

## Brand Personality

| Trait | Expression |
|-------|------------|
| Trustworthy | Tata AIA partnership, credentials, disclaimers |
| Warm | "Happiness Insured", senior-friendly UX |
| Expert | BNI, BCom financial planning background |
| Local | Borivali community, event sponsorships |

## Color Palette

| Token | Hex | Usage |
|-------|-----|-------|
| brand-navy | #0A1628 | Primary text, nav |
| brand-navy-light | #132038 | Hover, dark sections |
| brand-gold | #C9A227 | Accents, CTAs |
| brand-gold-light | #E8C547 | Gold hover |
| brand-teal | #1A6B7A | Secondary accent |
| brand-cream | #FAF8F5 | Background |
| brand-muted | #64748B | Secondary text |

Tokens are defined in `src/app/globals.css`.

## Typography

- Headings & body: Geist Sans (consider DM Serif Display for headings later)
- Numbers: Geist Mono

## Voice

**Do:** Plain language, benefit-led copy, explain jargon.

**Don't:** Fear selling, guaranteed return promises, unverified claims.

## Sample Headlines

- Hero: "Securing Your Future with Expert Wealth Management"
- CTA: "Book a Free Consultation"

## Assets Needed

- 9X Wealth logo (SVG)
- Professional headshot
- Event photos from Facebook/Instagram (with permission)
