# 9X Wealth Website

Professional website for **9X Wealth Financial Services** — Bijal Pathak, Tata AIA Life Insurance partner and wealth advisor based in Borivali, Mumbai.

> **Status:** Planning phase. See [docs/PLAN.md](./docs/PLAN.md) for the full blueprint.

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## 3 Template System

| URL | Purpose |
|-----|---------|
| [/studio](http://localhost:3000/studio) | Upload/edit content — populates all 3 templates |
| [/compare](http://localhost:3000/compare) | View Classic, Modern, Bold side by side |
| `/t/classic` · `/t/modern` · `/t/bold` | Individual template previews |

See [docs/TEMPLATES.md](./docs/TEMPLATES.md) for the full content flow.

## Tech Stack

| Layer | Choice |
|-------|--------|
| Framework | Next.js 15 (App Router) |
| Language | TypeScript |
| Styling | Tailwind CSS v4 |
| UI | shadcn/ui (planned) |
| Animation | Framer Motion (planned) |
| Icons | Lucide React |
| Forms | React Hook Form + Zod |
